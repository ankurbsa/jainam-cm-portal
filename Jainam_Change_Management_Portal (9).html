                ☁ OneDrive Sync — Setup Guide

                ⚠ Why sync fails from a local file: Browsers block cross-origin requests from file:// for security. Microsoft also requires authentication redirects for OneDrive downloads.
                ✅ Option 1 — Best: Open this portal from SharePoint (Recommended)
                1. Go to https://jainamin-my.sharepoint.com → your OneDrive
                2. Upload Jainam_Change_Management_Portal.html to your OneDrive
                3. Open the HTML file from OneDrive in your browser
                4. Now sync works — same Microsoft domain, no CORS block
                ✅ Option 2 — Get a Direct Download Link from OneDrive
                1. Open your OneDrive file → click Share
                2. Set to "Anyone with the link" → Copy Link
                3. Open the copied link in browser → file downloads
                4. Copy the final URL from the browser address bar after redirect
                5. Paste that URL in Settings → CM Config → OneDrive URL
                ✅ Option 3 — Use Local File + Manual Sync Workflow
                Keep your Excel on OneDrive as the master. When you need to work:
                1. Download the latest file from OneDrive (one click)
                2. Click "Load Local XLS" in the header
                3. Make changes → click "Save XLS"
                4. Upload the saved file back to OneDrive (replace)
